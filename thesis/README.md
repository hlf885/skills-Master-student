# thesis｜学位论文（规划中）

[仓库首页](../README.md)

计划提供 Skill：`master-thesis`。本目录目前只有规划，尚无可安装的 Skill。

## 规划范围

- **输入**：开题报告、中期报告、实验数据与图表源文件、已发表/在投论文、学校学位论文撰写规范；
- **主要功能**（草案）：
  1. 论文整体架构（绪论—理论基础—各研究内容章—系统实验—总结与展望）与章节衔接；
  2. 各章写作规范：绪论的研究现状由开题版本扩展更新、方法章的机理解释、实验章的结果与讨论分离；
  3. 图表公式规范（Visio、MathType、数据图核验与无水印）；
  4. 参考文献扩展与核实、摘要与结论口径一致；
  5. 查重前自查、外审意见回复、答辩通俗讲解稿；
- **沿用的共享规范**：与 mid-term 相同，并参考 [hlf885/thesis-writing](https://github.com/hlf885/thesis-writing) 的返稿审校规范。
