# proposal-ppt｜开题答辩 PPT

[仓库首页](../README.md)

开题答辩阶段使用的 PPT 制作 Skill。开题报告的写作见 [proposal](../proposal/README.md)。

| Skill | 版本 | 说明 |
| --- | --- | --- |
| [`master-proposal-ppt`](master-proposal-ppt/README.md) | 1.2.0 | 依据定稿的开题报告，在学校原生模板上生成可编辑的开题答辩 PPT：学习往届篇幅 → 抽取学校模板 → 提取开题报告 → 逐页规划 → 风格样页供选择 → 生成（可编辑公式）→ 渲染检查 |

## 适用对象

- 已完成开题报告、准备开题答辩的工科硕士研究生；
- 学校有固定的开题答辩 PPT 模板（默认演示西南科技大学模板，可替换为任意学校）。

## 与其他项目的衔接

输入为 [proposal](../proposal/README.md) 产出的开题报告；中期检查与学位论文答辩 PPT 分别放在 [mid-term-ppt](../mid-term-ppt/README.md) 与 [thesis-ppt](../thesis-ppt/README.md)。
