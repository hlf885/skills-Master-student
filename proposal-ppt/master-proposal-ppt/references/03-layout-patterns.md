坐标单位 cm，内容区宽 31.1（x 1.4 到 32.5），高约 13.8（y 3.3 到 17.1）。下面的写法都在 `assets/example_build.py` 里有可运行的示例。

## P1 图文并排（背景、研究对象）

左侧要点 16 到 17 cm 宽，右侧放 1 到 2 张图，图下深蓝图注条，右下一句深蓝结论条。

```python
s = d.content(1, "立题依据", "研究背景")
d.text(s, 1.4, 3.4, 16.6, 13.6, [要点1, 要点2, 要点3], size=18, bullet="▶", spacing=1.35, space_after=16)
d.picture(s, 图1, 18.6, 3.4, 6.7, 9.0, caption="图注")
d.picture(s, 图2, 25.6, 3.4, 6.9, 9.0, caption="图注")
d.bar(s, 18.6, 13.4, 13.9, 1.6, "一句结论", size=17)
```

## P2 流程条（作业流程、研究范围）

4 个等宽框 + 箭头，属于本课题的环节用红边框和深蓝标题，不属于的用灰色虚线框。框宽 7.0、间距 1.05，箭头放在间隙中。下面一行文字写清研究范围。

## P3 定义框 + 四卡片 + 归纳框（研究目的、难点）

顶部浅蓝定义框（高 2.2），中间 4 张 `card()`（宽 7.45、间距 0.4），向下箭头，底部红色虚线框写问题归纳。卡片正文 16 到 17 pt，每张不超过 40 字。

## P4 双卡片 + 两行标签（研究意义）

上半两张卡片左右并排（宽 15.2），下半两行：左侧 3.2 cm 宽深蓝竖标签（理论意义、工程价值，两字一行），右侧一句话 18 pt。

## P5 方法分类卡片 + 图 + 不足框（研究现状）

2 到 3 张分类卡片，每张：做法两三条 + 一条深蓝加粗的评价；右侧放一张代表性文献图（图注写清来源）；底部红色虚线框写 **不足：**。现状页一页只讲一个方向。

## P6 层次阶梯（数字孪生层次、发展阶段）

3 行错位排列，每行左侧深蓝或亮蓝块写层次名，右侧虚线框写 定义：代表工作 + 红色评价。每行向右缩进 1.2 cm 形成阶梯。

## P7 对比表 + 示意图 + 三条不足（方法对比）

左侧 `table()`（表头深蓝白字、隔行浅蓝），右侧两张小图，下方三个编号圆 + 红色虚线框各写一条不足。

## P8 编号趋势（发展趋势）

2 × 2 布局，每条：编号圆 + 深蓝标题条 + 一两行解释（17 pt），底部深蓝长条写本课题的切入路径。

## P9 框图 + 特点（研究内容总框架）

左侧放研究内容框图原图（加细边框），右侧 3 个编号特点卡片，底部亮蓝条说明各项研究内容的衔接关系。

## P10 四列研究内容

4 列等宽虚线框：顶部编号圆、深蓝标题条（研究内容全称）、正文（做什么，17 pt，50 字以内）、底部亮蓝产出条；列间放小箭头表示前后衔接。

## P11 目标 / 关键问题列表

左侧深蓝或亮蓝块写 目标n 或 关键问题n + 简称，右侧虚线框写内容；量化指标、需要解决的要点用红色加粗。目标用 2 × 2，关键问题用 3 行。

## P12 技术路线

左侧技术路线图原图（高度占满 13.7），右侧基本思路一段 + 4 个编号步骤。

## P13 方法页：流程图 + 公式

一侧放方法流程图（宽约 14.6 到 14.9），另一侧分 2 到 3 段：每段深蓝左对齐标题条（高 0.85）+ 公式 + 一两行说明。

```python
d.bar(s, 16.5, 3.3, 16.0, 0.85, "段落标题", size=14, align="l")
w, h = d.formula(s, 16.8, 4.35, r"R=\{(x_F,\boldsymbol{q}_m)\mid \dots\}", size=14, max_w=15.4, label="(3-10)")
d.text(s, 16.5, 4.55 + h, 16.0, 1.6, ["说明"], size=13)
```

`formula()` 返回公式的宽和高，后续元素用返回的高度往下排，避免重叠。公式里不要写中文，中文放到说明文字里。

## P14 实验设计页

左侧对比方法表 + 消融与工况卡片；右侧评价指标公式、辅助指标说明、虚实验证步骤（5 个浅蓝小条）。

## P15 三卡片 + 结论条（可行性分析）

三张等宽卡片（宽 10.0），每张 3 条要点 17 到 18 pt；底部深蓝条写结论。

## P16 创新点

每条：编号圆（1.3 cm）+ 深蓝标题条（17 pt）+ 虚线框两段（做法；与已有方法的区别，区别处用红色加粗）。

## P17 研究基础

左侧要点（16 pt），右侧成果截图带图注；数据表格页右侧放结果分析卡片，底部灰色小字写开题报告中的限定说明（临时模型、示意性设定、不作定量结论等），不能删。

## P18 工作条件

左列 已具备（深蓝竖标签 + 虚线框），右列 尚缺少（灰色标题条 + 红色向下箭头 + 解决途径）。

## P19 研究计划表

一张 `table()`，列宽约 4.6 : 15.5 : 11.0，行高 1.6 到 1.7，正文 14 pt，时间列加粗。

## P20 背景图墙（v1.1.0）

左侧 2 × 2 图片（上排开题报告中的对象模型图，下排网络实拍图，每张宽 9.8、高 6.4 到 6.6，带图注条），右侧 `chain()` 关键词链写因果（如 运行参数提高 → 部件活化需定期更换 → 只能远程维护，最后一条用红色），下面再放一张横幅实拍图；页底 8 号灰字写图片来源与许可。

## P21 现状分类条（v1.1.0）

仿往届做法：`class_row()` 左侧深蓝方向标签，右侧 2 到 3 条亮蓝做法条（做法：代表工作，评价），最后一条灰色写不足；两个方向上下排，右侧放一张代表性文献图；底部红色虚线小结框或浅蓝切入点条。一页讲两个方向。

## P22 目标与关键问题双栏（v1.1.0）

左栏深蓝标题条 研究目标，下列 4 个编号虚线框（目标名 + 一句含量化指标的短句）；右栏红色标题条 拟解决的关键问题，下列 3 个 问题n 竖标签 + 虚线框（问题全称）。

## P23 两项研究一页（v1.1.0）

左右各放一张方法流程图（宽约 15，带 研究一：××、研究二：×× 图注条），下方各放一个核心公式和一句说明；或左侧一张流程图，右侧依次放 优化目标公式、检查结果色块、对比方法框、评价指标公式、验证步骤小条。

## P24 关键数字色块（v1.1.0）

研究基础中的统计结果用 3 个并排色块表示（数字大字 + 名称小字，灰、蓝、红依次表示 不可行、部分可行、可行），下方红色虚线框写结论和限定说明。
