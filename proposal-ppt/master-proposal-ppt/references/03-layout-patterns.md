```python
s = d.content(3, "研究方案", "技术路线")
d.headline(s, "把作业位姿拆成两部分，分别离线计算、在线组合")
```

## 内容与版式对应

| 内容是什么 | 用哪种版式 | 典型页面 |
| --- | --- | --- |
| 背景、对象，有现成的图 | L1 图墙加因果 | 研究背景 |
| 对象加难点 | L2 图加流程加分列 | 研究对象与问题提出 |
| 发展阶段、研究空白在哪 | L3 演进图示 | 现状第一页 |
| 几类方法的对比 | L4 三线表 | 现状第二页、创新点 |
| 整体框架、技术路线 | L5 整页大图，或 L6 左图右步骤 | 研究内容、技术路线 |
| 方法、公式 | L7 图加公式 | 研究一到研究四 |
| 并列的两三组事 | L8 分栏细线 | 目标与关键问题、可行性 |
| 数据结果 | L9 大数字加图 | 研究基础 |
| 时间安排 | L4 三线表 | 研究计划 |

相邻两页不用同一种版式；同一种版式连续出现时换图的位置或栏数。

## L1 图墙加因果

左侧 2 × 2 图（每张宽 9.6），右侧细竖线隔开，三行因果，每行一个加粗短句加一行灰色解释，行间灰色 ↓，最后一行用主色。网络图片来源注放页底。

```python
d.fig(s, 图1, 1.6, 5.0, 9.6, 5.6, cap="图 ××", align="c")      # 四张同理
d.line(s, 22.3, 5.2, 22.3, 16.6, color=d.RULE)

d.text(s, 23.0, y + 1.05, 9.4, 0.9, ["放电时间增长"], size=17, color=d.MUTE)
```

## L3 演进图示

三个等宽阶段块（浅灰蓝底，无边框），最后一块主色填充白字表示本课题切入点，块间灰色 ›。细横线下写 尚缺（点缀色小标签）和三条对应的空白，与上方阶段对齐。

## L4 三线表

```python
d.rule_table(s, 1.6, 5.1, [4.0, 10.6, 7.4], rows, [1.0] + [1.45] * 6, size=17, head_size=14,
             colors=[d.INK, d.MUTE, d.NAVY_HEX])
```

rows[0] 为表头（灰色小字）；同组的后续行第一列留空表示归并；创新点表用 已有方法（灰）对 本课题（主色）。表格右侧可放一两张小图和 尚缺；表下细线加一句主色的 本课题：××。

## L6 左图右步骤

左侧技术路线图（宽 15.6），细竖线，右侧 基本思路（主色加粗两行）加四个步骤：主色 24 磅数字加 18 磅文字，步骤间细横线。不用编号圆。

## L7 图加公式

两种排法交替使用：

- 两图并排，各自下方放公式（`d.formula(..., label="(3-4)")`）和一行解释；
- 左图右文，右侧上下两段，各有灰色小标签、公式和两条要点，段间细横线。

公式只放定义式、目标函数、评价指标；符号解释和追问写进备注的备查部分。

## L8 分栏细线

两栏或三栏，栏间细竖线；每栏一个灰色小标签，下面若干行，行间细横线；每行左侧加粗短名（主色或深灰），右侧 18 到 20 磅说明，关键数字用 `__ __` 主色加粗。关键问题的编号写成点缀色 问题1，不用色块。
