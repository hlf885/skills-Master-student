# 08 审美、去 AI 味与风格选择

[返回 SKILL.md](../SKILL.md)

本篇来自第二轮用户修改意见（存在的问题-V2）：第二版配色差、创新点页 AI 味重、字太小、公式被问到答不上。修订前对照学习了 [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)、anthropics/skills 的 pptx 技能、Gabberflast/academic-pptx-skill、MiniMax-AI/skills 的 pptx-generator 以及几篇讨论 AI 生成幻灯片通病的文章，整理成下面的规则。

## 一、先确认宗旨和需求，再动手

开题答辩 PPT 的宗旨：**让评委在 8 到 10 分钟里听懂并记住 做什么、为什么做、怎么做、凭什么能做成**。页面是给评委看的提示，讲稿是给答辩人念的话，追问的答案放在备注的备查部分。

动手前按顺序确认，用户说直接做时可以合并成一次提问：

1. 汇报时长、是否限页；
2. 用户最在意什么（例如：简洁高效、图多字少、公式要讲清楚）；
3. 风格：先出风格样页让用户挑（见第五节），不要凭自己的喜好定；
4. 有没有特别不喜欢的样子（往届 PPT、上一版里哪一页）。

收到修改意见时同样先复述理解、确认，再改。

## 二、什么是 AI 味

AI 味指一看就是套模板批量生成的痕迹：每页都一样，元素是装饰不是信息。常见表现：

| AI 味 | 改成 |
| --- | --- |
| 每段文字都垫一个彩色条、色块或卡片 | 文字直接放在页面上，用留白和细线分组 |
| 编号圆、图标、左侧色条、标题下的装饰横线 | 去掉；需要编号时用正文同色的数字 |
| 虚线框、圆角框套文字 | 不套框；要强调就加粗或换成标题色 |
| 通栏深色标题条，白字写一句话 | 结论句直接用标题色加粗写在页面顶部 |
| 红色加粗关键词满页都是 | 全篇只留一个点缀色，只标研究空白或本课题的不同之处 |
| 每页同一个版式，等宽卡片排排坐 | 版式按内容选（见第四节） |
| 字小、字多，要点一律 30 字一条 | 字大、字少，完整的话写进备注 |
| 浅米色、渐变、阴影、多种颜色 | 模板底色 + 一个主色 + 一个点缀色 + 灰 |
| 空洞的大词：赋能、闭环、全方位 | 开题报告原话 |

自查办法：把页面上所有色块、框、条、圆删掉，信息是否一点没少？没少，说明它们都是装饰，删掉。

## 三、全篇统一的规则（选定风格后不再变）

以默认风格 学术极简 为例，其余风格只改颜色和字号，规则相同：

| 项 | 规则 |
| --- | --- |
| 颜色 | 主色（模板深蓝 274F7F）只用于结论句、表中本课题一列、少数重点；正文深灰黑 1F2933；次要文字灰 6B7280；分区细线浅灰 C8D0DB；点缀色暗红 A33B2B 只标 尚缺 和研究空白；浅灰蓝 F1F4F8 底块偶尔用，不套文字框 |
| 结论句 | 每个内容页顶部一句 22 磅主色加粗的结论句，30 字以内，说这一页要评委记住什么；只读全部结论句应能听懂整个开题 |
| 字号 | 正文 17 到 20 磅，表格 16 到 19 磅，小标签 14 磅，图注 12 磅灰色，来源注 8 到 10 磅；正文低于 16 磅就删字或拆页 |
| 分组 | 用留白和 0.5 到 0.75 磅浅灰细线；表格用三线表（顶线、表头线、底线），不用竖线和底色 |
| 图 | 等比放入，图下灰色小字图注 图 ××，不用深蓝图注条 |
| 强调 | 一页最多两处主色加粗；不用红色加粗 |
| 对齐 | 左对齐为主，同一页内元素的左边线、顶边线对齐 |

`swust_kit` 对应函数：`set_theme()`、`headline()`、`fig()`、`rule_table()`、`line()`、`big_number()`、`notes(text, ref=)`。旧的 `bar()`、`card()`、`circle_num()`、`chain()`、`class_row()` 和 `picture(caption=)` 的深蓝图注条会产生 AI 味，新做的 PPT 不再使用。

## 四、全篇统一，但不能页页一个样

风格统一的是颜色、字号、结论句位置、图注写法这些规则；每一页的版式由这一页的内容决定。规划逐页清单时为每页写明版式，并检查：

- 相邻两页不用同一种版式（两页研究方案都是 图加公式 时，一页图在左一页图在右，或一页两图并排）；
- 全篇至少用到 5 种版式；
- 每种版式都能说出为什么适合这页的内容。

内容到版式的对应见 `03-layout-patterns.md`：并列的事用分栏，对比用三线表，演进和定位研究空白用图示，流程和框架用大图，数据用大数字加图，计划用表。

## 五、风格样页先行，让用户自己挑

风格是用户的审美决定，说不清，看了才知道。规划完成、动手做整套之前：

1. 从开题报告里挑 4 页有代表性的内容（一页现状、一页创新点、一页方法、一页前期结果），按 `scripts/style_gallery.py` 里 `DEMO` 的结构写一个 `my_content.py`；
2. 运行 `python3 scripts/style_gallery.py <本Skill目录> 输出目录 --content my_content.py --render`，每套风格得到一份 pptx 和一张 2 × 2 拼图；
3. 把拼图发给用户，说明每套风格的特点（脚本会打印），问用户选哪套、哪页要改；
4. 用户不满意时，按意见调颜色或换风格再出一轮，不要直接做整套。

`assets/style_gallery/` 里有用中性示例内容（虚构课题）渲染好的五套风格，用户还没给出开题报告时可以先给他看：

| 风格 | 特点 | 适合 |
| --- | --- | --- |
| 学术极简 | 模板深蓝标题，浅灰细线分区，暗红只标研究空白 | 大多数开题，默认 |
| 期刊黑白 | 近黑标题，全篇黑白灰，只用亮蓝标本课题 | 偏理论、公式多的课题 |
| 浅色分区 | 无边框浅蓝灰底块分组，赭色点缀 | 内容条目多、需要明显分组 |
| 深色重点 | 平时极简，本课题做法和关键数据放进深蓝反白块 | 想让创新点和结果一眼可见 |
| 大字结论 | 结论句 28 磅，要点更少，证据靠图和大数字 | 讲述节奏快、限时紧 |

选定后在生成脚本开头 `d.set_theme("风格名")`，全篇不再改。

## 六、公式页的备注

页面上的公式只放定义式、目标函数和评价指标，旁边一行字说它干什么。备注分两部分：

- 讲稿：要念的话，用口语解释公式在做什么，不念符号；
- 备查：`notes(slide, 讲稿, ref=备查)` 写入，不计入时长。每个公式写清 每个符号的含义、为什么这样设计、取值怎么定，再列 2 到 3 个可能的追问和建议回答；报告中有但页面没放的公式也写进备查。所有内容都要能在开题报告里找到出处，报告里没写的参数取值不要编，回答写 由实验确定 或 按需要的置信程度选取。
