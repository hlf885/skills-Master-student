# 07 备注讲稿、网络实拍图与个人成果留白页

[返回 SKILL.md](../SKILL.md)

本文件来自第一轮用户修改意见（v1.1.0）：汇报限时 8 到 10 分钟，初稿页数和文字都太多；PPT 要图文并茂，研究背景可以补充真实网络图片；每页要有备注讲稿；研究基础要留一页空白给个人成果。

## 一、备注讲稿

用户答辩时一边翻页一边照着备注念，所以：

1. **每一页都写备注**，包括封面（自我介绍和题目）、目录（一句话过渡）、结束页（请老师批评指正）。
2. **页面只放关键词、短句、图和公式**，完整的句子写进备注。页面上的一条要点，在备注里展开成一两句话。
3. **按时长控制总字数**：讲稿按每分钟约 250 字（只数汉字和字母数字，标点不念）估算。8 到 10 分钟的汇报，备注总量约 2000 到 2300 字；留白页先按 30 秒预留。`d.notes(slide, 文字)` 写入备注，`d.notes_report()` 逐页打印字数和秒数。
4. **每页时长分配**（8 到 10 分钟，17 页左右）：

| 页面 | 备注字数 | 约用时 |
| --- | --- | --- |
| 封面、目录、计划、结束 | 20 到 60 | 5 到 15 秒 |
| 研究背景、研究对象与问题 | 170 到 210 | 40 到 50 秒 |
| 研究现状（每页） | 160 到 180 | 约 40 秒 |
| 研究内容、目标与关键问题、技术路线 | 150 到 180 | 35 到 45 秒 |
| 方法页（每页两项研究） | 180 到 200 | 约 45 秒 |
| 可行性、创新点、研究基础 | 130 到 150 | 30 到 35 秒 |

5. **讲稿写法**：口语化但不随意；第一句说这页讲什么，中间按页面从左到右、从上到下讲，最后一句收束到本课题。提到图时说 左图、右上图，和页面位置一致。数字与页面、开题报告一致。仍然不用引号和破折号，不用 我们（可以用 本课题、我）。
6. **需要用户补充的地方用括号写明**，例如 （姓名）、（导师姓名）、（此页粘贴个人成果后在这里补充讲稿）。

## 二、研究背景的网络实拍图

开题报告里的图多是三维模型和方法示意图，研究背景页需要一两张真实场景照片让评委快速进入情境。

1. **只用真实照片**：装置实景、检修现场、同类机器人实物等，与课题直接相关；不自己画，不用 AI 生成，不用来源不明的图。
2. **优先选可自由使用并能注明许可的来源**：Wikimedia Commons（CC BY、CC BY-SA、公有领域）最方便，可用其 API 按关键词检索并读取作者、许可和原图尺寸：

```js
// 在浏览器中打开 commons.wikimedia.org 后执行
const r = await fetch('/w/api.php?action=query&list=search&srnamespace=6&srlimit=8&format=json&srsearch=' + encodeURIComponent('tokamak divertor')).then(r => r.json());
// 再用 prop=imageinfo&iiprop=url|size|extmetadata&iiurlwidth=1800 取下载地址、作者(Artist)、许可(LicenseShortName)
```

   机构官网图片（ITER、EUROfusion 等）若要使用，先确认其使用条款，并在页面写明出处。不使用人物肖像照片。
3. **清晰度**：长边不小于 1600 像素，放进 PPT 前看一眼有没有水印、外文标注遮挡主体。
4. **下载与落盘**：工作环境往往不能直接访问外网。可在浏览器里把图片取成 Blob 后以 `a.download` 触发下载，文件会进入用户的下载文件夹；若无法读取下载文件夹，请用户把文件拖到已连接的开题目录（例如 `开题答辩PPT\网络图片\`），再继续。文件名统一以 `web_` 开头并写明内容。
5. **页面标注**：图下图注条写中文说明并带装置名，如 人员进入真空室检修（DIII-D）；页面底部用 8 号灰字统一写来源：作者、许可，例如 DIII-D：Rswilcox，CC BY-SA 4.0。
6. **只用在研究背景（必要时研究对象页）**，其他部分的图仍然只来自开题报告和用户自己的工作。

## 三、个人成果留白页

研究基础与工作条件部分固定留一页：

```python
s = d.blank_page(5, "研究基础与工作条件", "研究基础：个人成果")
d.notes(s, "（此页留白：粘贴比赛获奖、论文、专利等个人成果后，在这里补充对应讲稿，约30秒。）")
```

只保留模板页眉和页码，内容区完全空白，不放提示文字（提示写在备注里），用户自己粘贴截图或文字。不要替用户填写成果，也不要从记忆、简历或其他文件中查找。

## 备查部分（v1.2.0）

`d.notes(slide, 讲稿, ref=备查)`：讲稿是要念的话，计入时长；备查写在 【备查，不念】 之后，不计入时长，用来应对追问。

- 公式页：每个公式写 符号含义、为什么这样设计、取值怎么定；报告里有但页面没放的公式也写上；
- 每个内容页都可以写 2 到 3 个评委可能问的问题和建议回答，答案只用开题报告里的内容，报告没写的不要编；
- 前期结果页写清数字的来龙去脉（如 450 = 142 + 278 + 30）。
