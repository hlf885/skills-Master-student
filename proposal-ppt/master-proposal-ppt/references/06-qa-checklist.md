# 06 交付前检查清单

[返回 SKILL.md](../SKILL.md)

## 内容

- [ ] 题目与开题报告一致，一字不差；
- [ ] 每页文字都能在开题报告中找到出处，没有新增事实、数字、文献、成果；
- [ ] 量化指标、实验数字、表格数据逐个核对一致；
- [ ] 公式与开题报告一致，编号一致，符号含义在说明中交代；
- [ ] 限定语（拟、初步、示意、临时模型、不作定量结论）没有被删掉；
- [ ] 研究内容、研究目标、关键问题、技术路线、创新点前后对应，数量一致；
- [ ] 工作计划表的时间段与开题报告一致；
- [ ] 封面个人信息留空或由用户填写，学校名称为当前模板学校。

## 审美（见 08）

- [ ] 动手前确认过宗旨与需求，风格由用户在风格样页里选定；
- [ ] 每个内容页有结论句，只读结论句能听懂整个开题；
- [ ] 没有彩色条垫文字、编号圆、虚线框、通栏深色标题条、红色加粗、装饰线；
- [ ] 全篇只有一个主色、一个点缀色加灰；
- [ ] 版式按内容选，相邻两页不用同一种版式，全篇至少 5 种版式；
- [ ] 删掉所有色块和线框后信息不少（不少就删）。

## 版式

- [ ] `swust_kit` 没有未处理的溢出警告；
- [ ] 渲染总览中没有文字出框、元素重叠、压住页码块；
- [ ] 图片等比缩放，没有拉伸；图注为灰色小字，没有折行到图外；
- [ ] 正文不低于 16 pt，表格不低于 16 pt，图注 12 pt；
- [ ] 每部分的页眉编号、部分名称、页码连续正确；
- [ ] 同类元素（结论句位置、图注、细线、颜色）全篇一致。

## 讲稿与时长

- [ ] 每一页都有备注，封面、目录、结束页也有；
- [ ] `notes_report()` 估算的总时长落在用户要求的区间内（默认 8 到 10 分钟，含留白页预留 30 秒）；
- [ ] 备注与页面内容、开题报告数字一致，提到的图的位置说法与页面一致；
- [ ] 需要用户补充的地方在备注里用括号标出；
- [ ] 有公式的页，备注的备查部分逐个解释符号、设计理由和取值，并列出可能的追问与回答，内容都能在开题报告里找到出处。

## 图片

- [ ] 研究背景页有真实照片，清晰、无水印遮挡；
- [ ] 每张网络图片都在页面上写明作者和许可，且许可允许使用；
- [ ] 除研究背景外，没有使用开题报告和用户工作以外的图片；
- [ ] 研究基础留有一页空白页给个人成果。

## 规范

- [ ] 没有引号、破折号、感叹号；
- [ ] 没有 本文、我们、笔者；
- [ ] 研究方案小标题为 研究一：×× 形式；
- [ ] 主色加粗每页不超过两处，没有红色加粗。

## 交付

- [ ] pptx 与生成脚本一起交付，脚本放在用户本地开题目录；
- [ ] 告诉用户总页数、各部分页数、讲稿总字数和预计时长、待填写项、网络图片来源；
- [ ] 新版另存为新文件名，不覆盖旧版；给出本轮修改记录表；
- [ ] 用户的修改意见中属于通用规律的，已写回本 Skill 并升版本。
