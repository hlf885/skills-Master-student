# mid-term｜中期检查（规划中）

[仓库首页](../README.md)

计划提供 Skill：`master-midterm`。本目录目前只有规划，尚无可安装的 Skill。

## 规划范围

- **输入**：开题报告（含《课题定位卡》、研究内容、工作计划、参考文献核实表）、开题专家意见、已完成的实验与代码、阶段性成果；
- **主要功能**（草案）：
  1. 逐项对照开题计划，梳理完成情况、偏差与原因；
  2. 回应开题专家意见，说明采纳与调整；
  3. 阶段成果的规范表述（图表、数据、对比实验），严格区分“已完成”与“拟完成”；
  4. 存在问题、风险与调整方案；后续工作计划与预期成果；
  5. 中期答辩通俗讲解稿与 PPT 提纲；
- **沿用的共享规范**：GB/T 7714 著录、去 AI 味与预判式写作、苏格拉底式追问、Visio/MathType 流程（以 `proposal/master-proposal/references/` 为基准同步）。
