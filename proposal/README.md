## 适用对象

- 工科（机器人、智能制造、控制、电子信息等）应用研究型硕士开题；
- 课题依托纵向或横向科研项目；
- 学校使用“立题依据 / 研究内容和目标 / 研究方案及可行性 / 创新之处 / 研究基础与工作条件 / 工作计划”的表格式开题报告（其他格式也可按学校模板调整）。

## 与后续环节的衔接

开题阶段产出的《课题定位卡》、参考文献核实表、Visio 图源文件和工作计划，将作为 [mid-term](../mid-term/README.md) 中期检查与 [thesis](../thesis/README.md) 学位论文写作的输入，请妥善保存。
