# 07 语言规范：学术文风、去 AI 味、预判式写作

参考并改写自：hlf885/thesis-writing 的写作规范（保持作者声音、减少无效防御性措辞、按重要性分配篇幅）、op7418/Humanizer-zh（中文模板化表达检查）、Imbad0202/academic-research-skills 的 Writing Quality Check 与 Claim-Strength Ladder（论断强度不可悄悄改变）。

**原则：** 目标是写得准确、清楚、像作者本人，不是为了“骗过检测器”。不故意制造错别字、不随机替换同义词、不打乱逻辑。

## 一、开题报告的文风

- **正式、平实、具体**：主语明确、动词具体；少用“进行”“实现了……的提升”这类空壳结构；
- **“拟”字到位**：尚未完成的工作一律用“拟”“将”“计划”；已完成的前期工作才用“已”；
- **术语统一**：同一概念全文一个名称（如“数字孪生体/孪生体”定一个）；英文缩写首次出现给全称：“同时定位与地图构建（Simultaneous Localization and Mapping，SLAM）”；
- **称谓统一**：“本课题”或“本研究”二选一，避免与“本文”“我们”“我”混用（可行性分析中谈个人基础时可用“申请者/本人”，全篇一致）；
- **数字与单位**：数字与单位之间空格规范统一（如“5 km/h”“0.2 mm”），量和单位符合国家标准；
- **标点**：中文正文用全角标点；英文、公式、参考文献内用半角；不用“~”表示范围（用“–”或“至”）。

## 二、去 AI 味：开题报告中最常见的模板化表达

逐条检查，确有问题才改；不是禁词表。

| 类型 | 典型表达 | 处理方式 |
| --- | --- | --- |
| 空洞开头 | “随着科学技术的飞速发展”“在当今时代背景下” | 换成有信息量的背景：具体政策、数据、事件 |
| 意义拔高 | “具有重大而深远的意义”“标志着……新时代”“填补了国内外空白” | 写清对谁、解决了什么、带来什么可检验的变化 |
| 高频空词 | 赋能、助力、深度融合、全方位、多维度、无缝、闭环（非控制意义）、至关重要、不可或缺 | 有具体含义的保留（如控制中的“闭环”），否则删或换具体动词 |
| 假对比 | “不仅是……更是……”“不是……而是……” | 两部分都有信息才保留 |
| 强凑三段 | 每处都是“三个方面”“三大挑战” | 有几点写几点；两点也可以 |
| 句尾拔高 | “……，彰显了……的巨大潜力”“为……奠定了坚实基础”（反复出现） | 全文“奠定坚实基础”类收尾不超过 2 次 |
| 进行+动词 | “对系统进行测试”“进行优化处理” | 直接写“测试系统”“优化” |
| “的”字堆叠 | “基于……的……的……的方法” | 调整语序或拆句 |
| 元叙述 | “本节将对……进行详细介绍”“下面让我们来看” | 直接开始说内容（章节导语一句即可） |
| 机械序数 | 每段都“首先、其次、最后” | 有先后顺序时保留；并列内容改为自然衔接 |
| 夸张形容 | “极具挑战性”“前所未有”“堪称” | 用事实说明难在哪里 |
| 套话收尾 | “综上所述，……具有广阔的应用前景”（每节都有） | 收尾写出本节结论或引出下一节的缺口 |

### 改写示例（教学用）

- 原：随着人工智能技术的飞速发展，机器人在各个领域发挥着越来越重要的作用，具有重大而深远的意义。
- 改：《“十四五”机器人产业发展规划》提出面向特殊环境加快研制特种机器人^[n]^。在核电站巡检等场景中，人员进入高辐射区域存在受照风险，机器人替代人工的需求迫切。

（改写只使用了可核实的事实；新增的政策出处必须经过核实再引用。）

## 三、论断强度：不可悄悄拔高或降低

- 等级：可能有助于 < 与……相关 < 能够预测 < 有助于 < 能够提升 < 能够保证/证明；
- 开题阶段没有实验结果，绝大多数论断停留在“拟”“预期”“有望”；
- 引用他人工作时，强度不超过原文（原文说“在仿真中验证”，不能写成“在实际中广泛应用”）；
- 慎用：“首次”“唯一”“完全解决”“国际领先”“填补空白”——除非有检索证据；
- 修改时也要保护必要的限定词（“在……条件下”“初步”“仿真中”），删掉它们等于改变了结论。

## 四、两种“防御性写作”

### 4.1 要删的：无效防御性措辞

- 反复自谦和预先辩解：“由于本人水平有限，难免存在不足”“本研究虽然不能完全……但……”（重复出现）；
- 假想敌式辩论：“有人可能会认为……但实际上……”且没有具体对象；
- 与论证无关的免责声明。

这些内容占篇幅、显得心虚。真实的限制条件、适用范围、风险与退路**必须保留**，并且集中写在方案与可行性部分。

### 4.2 要做的：预判式写作（答辩防御）

在写作时站到答辩专家的位置，提前把他们会问的问题在正文中答好：

| 专家常问 | 正文中应提前写清的位置 |
| --- | --- |
| 为什么非做不可？ | 1.1 立项必要性：痛点 + 后果 + 项目需求 |
| 和别人有什么不同？ | 1.2 每小节末的不足 + 第四部分创新点 |
| 研究内容之间什么关系？ | 2.1 导语与框图，内容条目中的“为后续……提供……” |
| 目标怎么检验？ | 2.2 目标的指标/验证方式 |
| 难点在哪里，凭什么能解决？ | 2.3 关键问题 + 3.2 理论分析中的拟改进点 |
| 做不出来怎么办？ | 3.3 可行性 + 评估表中的降级方案（可在正文中简述） |
| 工作量够不够、会不会太大？ | 研究内容 3–4 项 + 工作计划节点 |
| 平台和数据从哪来？ | 3.3 条件可行性（第五部分由用户写） |

写完后用这张表逐条自查：每个问题都能在正文中找到明确回答。

## 五、学习用户的写作风格

如果用户提供了本人写过的文字（小论文、课程报告），从中提取：句长习惯、常用连接词、术语偏好、引用句式、段落长度。写作时作为**软约束**；学科规范和学校要求优先。不把样本中的事实、数据搬进开题报告。
