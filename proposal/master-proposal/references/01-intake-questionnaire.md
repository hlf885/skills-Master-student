# 01 资料收集与分轮提问

开题报告是应用研究，依托真实项目。写得好不好，取决于你对项目理解得深不深。所以第一件事不是写，而是问。

## 开场白（可直接使用，按用户语气微调）

> 我会以你所在领域博士生导师兼高级工程师的身份，和你一起完成开题报告。动笔之前，我需要先把你的项目和课题弄清楚。接下来我会分几轮提问，每轮几个问题；同时请你把**与项目相关的全部资料**发给我。
>
> 请注意：资料中的姓名、学号、导师姓名、单位内部编号、项目合同编号与金额、涉密参数、未公开的人员信息等，请先删除或用 XXX 代替。
>
> 你把资料发完、问题答完后，请明确告诉我“资料已全部提供，可以开始”。在此之前我只做整理和追问，不会开始分析和写作。

## 资料清单（让用户逐项勾选，详见 `assets/intake-checklist.md`）

| 类别 | 资料 | 用途 |
| --- | --- | --- |
| 项目 | 项目申报书/任务书/合同技术附件（脱敏）、项目考核指标、项目进度安排 | 立项必要性、研究目标与量化指标、工作计划 |
| 课题 | 拟定题目、导师意见、学生在项目中承担的具体任务 | 研究内容边界 |
| 学校 | 学校开题报告空白模板、字数与格式要求、引用格式要求、开题时间 | 版式与节点 |
| 平台 | 实验平台/机器人/传感器/软件环境的公开参数与照片（无水印、可公开） | 研究方案、可行性 |
| 前期 | 已做的仿真、实验、代码复现截图、阶段性数据（学生本人的） | 可行性分析；第五部分由学生自写 |
| 文献 | 已读的核心文献清单或 PDF、导师推荐文献、课题组已发表论文 | 研究现状与参考文献 |
| 参考 | 同课题组往届开题报告（如有） | 风格与边界对标，不照搬 |

## 分轮提问

每轮 3–5 个问题；先问最影响写作方向的。用户答完一轮再进入下一轮。能用 AskUserQuestion 时，把可选项做成选择题，其余开放问题放在消息中。

### 第一轮：项目与课题定位

1. 你的课题依托哪个项目（可脱敏描述类别，如“省重点研发”“企业横向”“国防基础”）？项目要解决的工程问题是什么？
2. 在项目中，你个人负责哪一块？哪些内容是课题组其他人在做（要避免写进来抢别人的工作）？
3. 拟定题目是什么？导师对题目有无明确意见？题目是否已不可改动？
4. 研究对象是什么（具体机器人/设备/系统/场景）？应用场景是什么环境（工业、核、化工、医疗……）？
5. 学校开题时间、答辩形式（PPT 时长、专家构成）是什么？

### 第二轮：问题与需求

1. 现场目前是怎么做的？最大的痛点是什么（效率、安全、精度、成本、可靠性）？有没有具体案例或数据？
2. 你认为现有方法不够用的根本原因是什么？
3. 项目任务书或合同里有没有考核指标（精度、成功率、时延、速度、寿命、覆盖率等）？
4. 研究完成后，要交付什么：算法、系统、样机、软件、实验报告、专利、论文？

### 第三轮：技术路线与条件

1. 你目前倾向的方法或技术路线是什么？为什么选它？有没有备选方案？
2. 已经具备哪些软硬件条件？还缺什么？缺的东西有无解决途径？
3. 已经做了哪些前期工作（复现、仿真、实验）？结果如何？
4. 你觉得最难的一步是什么？如果这一步做不出来，有没有退路？
5. 可投入的时间：距离中期答辩、毕业答辩分别还有多久？

### 第四轮：写作偏好与边界

1. 学校要求的模板、字数和参考文献格式是什么？参考文献数量有无特别要求（本 Skill 默认 56–66 条）？
2. 是否有你自己写过的文字（小论文、报告）可以让我学习你的写作风格？
3. 哪些内容必须写进去，哪些内容不能写（涉密、未公开、别人的工作）？
4. 是否需要我帮你在 Visio 中作图、在 MathType 中录入公式？你的电脑是否已安装这两个软件？

## 量化指标的专门询问（硬性规则，不可省略）

核对完资料和需求后，单独发一条消息：

> 关于研究目标的写法，需要你明确决定：
> (a) 使用量化指标——我从项目文件里找到了这些指标：____；请确认数值和口径，或补充；
> (b) 不使用量化指标——用定性方式描述目标（例如“实现……”“显著提升……”并给出可检验的验证方式）；
> (c) 部分量化——只对 ____ 等有依据的目标量化。
> 你选哪一种？

记录用户的选择；后续 2.2 研究目标、3 研究方案中的验证指标、答辩讲解稿中的“做成什么样”保持同一口径。

## 进入分析的门槛

以下条件全部满足，才进入阶段 2：

- [ ] 用户已明确确认“资料已全部提供”；
- [ ] 已复述项目背景、研究对象、学生分工，用户已确认无误；
- [ ] 已知学校模板与格式要求（没有则用本 Skill 默认格式，并告知用户）；
- [ ] 已列出“仍缺失但不影响开始”的信息，用户同意先这样推进。

## 资料处理注意事项

- 读取资料后，只在开题报告里使用可公开的信息；项目编号、单位名称等按用户要求写成“XXXX”。
- 用户提供的图片，检查是否清晰、有无水印、是否可公开使用。
- 往届开题报告只用来学习结构和边界，不复制段落；发现可能雷同的内容要改写并提醒用户查重。
