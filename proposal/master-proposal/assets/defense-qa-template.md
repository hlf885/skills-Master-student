# 可能会被问的问题（模板）

课题：＿＿＿＿＿＿＿＿（对应初稿 V＿）

用法：每题先说结论，再说依据，控制在一分钟内。回答中的数据、公式编号和表号以当前版本报告为准。“报告位置”写正文中已经写好的依据，被追问时可以直接翻到那一页。没有做完的工作如实说没做完。

写法说明见 `references/06-defense-plain-language.md` 第七节。样例：本仓库作者开题报告的问答（懂行 12 问、不懂行 9 问），结构与本模板相同。

## 一、懂行的答辩专家可能会问的问题（10–12 问）

按下面的方向出题，换成本课题的具体内容。

| 方向 | 问题写法示例 |
| --- | --- |
| 题目中的动作词 | 你这是＿＿，哪里体现了＿＿（题目中的优化、设计、控制等）？ |
| 为什么不用常见方法 | 为什么不用＿＿（领域里流行的方法）？ |
| 结果的性质 | 得到的是最优解吗？适用范围是什么？ |
| 与最接近工作的区别 | 和＿＿等的方法相比，本质区别在哪里？ |
| 失败或未决情况 | ＿＿（检查、求解、识别）失败时怎么处理？ |
| 关键参数怎么定 | ＿＿（阈值、裕度、权重）是怎么确定的？ |
| 更新与一致性 | 场景或数据变化后，结果怎样更新，会不会漏掉？ |
| 关键概念的本质 | 你的＿＿（如数字孪生）和一般的＿＿（如仿真）有什么区别？ |
| 前期结果可信度 | 前期结果基于＿＿（临时模型、替代参数），可信吗？ |
| 实验设计 | 对比方法和评价指标为什么这样设？ |
| 工作量与进度 | 工作量和时间够吗？中期之前完成什么？ |

每题格式：

**问 n：＿＿＿＿？**
回答要点：先一句结论。再写两三句依据，依据要用报告中的数据或公式。
报告位置：＿＿节，式（＿），表＿

## 二、中间档专家可能会问的问题（4–6 问）

中间档指相关领域的专家，懂工程或机器人，但不做这个方向。他们常问方法的思路、和熟悉方法的区别、工程上能不能用。回答时少用公式，用流程讲清楚。

**问 n：＿＿＿＿？**
回答要点：＿＿＿＿

## 三、不懂行的答辩专家可能会问的问题（8–10 问）

| 方向 | 问题写法示例 |
| --- | --- |
| 一句话说课题 | 请用一句话说说你在做什么。 |
| 为什么必须这样做 | 为什么不能靠人＿＿？ |
| 现在的做法有什么问题 | 现在靠＿＿不行吗？ |
| 关键概念 | ＿＿（如数字孪生）是什么？和＿＿（如三维动画）有什么区别？ |
| 题目中的动作词 | 你说的＿＿（如优化）具体指什么？好在哪里？ |
| 有什么用 | 做出来有什么用？ |
| 进展 | 现在做到哪一步了？ |
| 风险 | 算出来的结果到现场不行怎么办？ |
| 与项目的关系 | 这项工作和你所在的项目是什么关系？ |

每题格式：

**问 n：＿＿＿＿？**
回答要点：不用公式和术语，先说一句结论，再用身边的例子讲清楚，比喻要注明不完全相同的地方。

## 四、回答时注意

- 没有完成的工作如实说明：＿＿、＿＿还没有完成，不要说成已经做好；
- 不说全局最优、首次、填补空白一类的话，说在什么范围内、与已有方法相比怎样；
- 被问到引用的文献时，按《参考文献导读》中的必读文献作答，只核对过题录的文献不展开细节；
- 前期数据带上前提（如临时模型、示意性设定）。
