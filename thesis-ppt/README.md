# thesis-ppt｜学位论文答辩 PPT（规划中）

[仓库首页](../README.md)

计划提供 Skill：`master-thesis-ppt`。本目录目前只有规划，尚无可安装的 Skill。

## 规划范围

- **输入**：学位论文终稿、已发表成果、中期与预答辩意见；
- **主要功能**（草案）：沿用 [proposal-ppt](../proposal-ppt/README.md) 的模板抽取、生成库和检查流程，页面结构改为 研究背景与意义、研究内容与技术路线、各章工作与结果、结论与展望、攻读学位期间成果、致谢；
- 实验结果、成果清单与论文终稿逐项一致，不夸大。

## 开发约定

按 [仓库管理规范](../docs/REPOSITORY_GUIDE_ZH.md) 在 `thesis-ppt/master-thesis-ppt/` 下创建 Skill，并更新本文件与根目录索引。
